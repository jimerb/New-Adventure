# Room maps

Generated by `tools/make-maps.ps1` from `data/rooms.json`. Do not hand-edit.

Each room is a **40 x 7 cell** grid. One cell is 4 x 16 units in the 160 x 96
unit play area. `#` is solid wall, `.` is open floor. Rooms marked
*repeated* draw the same left half twice instead of mirroring it -- the only
two are `14` and `15`, which is what makes that corner of the black maze feel
subtly wrong.

Exit order everywhere in this project is **up, right, down, left**. Exit
values `>= $80` are game-variant indirections; see `data/behaviour.json`.
